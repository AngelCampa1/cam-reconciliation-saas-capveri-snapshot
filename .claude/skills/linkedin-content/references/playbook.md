# LinkedIn Playbook — CapVeri Reference

## Algorithm Quick Rules (2025–2026)

| Rule | Impact |
|---|---|
| Outbound links in post body | −70% reach |
| Unaltered AI-generated text | −30% reach, −55% engagement |
| 3+ consecutive same-format posts | −20% reach |
| Engagement pods (static group) | Capped to that group only |
| Comments ≥15 words | 2× amplification vs. short replies |
| Videos 60–120 seconds | Algorithmic optimum for retention |
| Golden hour (first 60 min) | Primary evaluation window — respond to all comments |

**Dwell time is the #1 ranking signal.** Every format choice must maximize time-on-post.

## 7 Post Templates

### 1. Story Template
Hook → "learned this the hard way" → 3–4 short narrative paragraphs → Key takeaway → Question → CTA to save

### 2. List Template
"X things I wish I knew about [topic]" → Numbered list, 5–7 items, one line each → "Which one surprised you most?" → Save CTA

### 3. Case Study Template
Quote with surprising result → Before state (the problem) → After state (the solution) → 3 steps taken → CTA: "Comment [WORD] for the full framework"

### 4. Insight Template
"Most people think [X]... Truth is [Y]" → 3–4 paragraphs dismantling the belief with data → New paradigm → "Share with someone who needs this"

### 5. Question Template
"Quick question:" → Creator's perspective in 2 paragraphs → "What's your take?" → Comment prompt

### 6. Framework Template
Introduce a named proprietary framework → Step 1, 2, 3... → Proof: "[Company/person] used this and got [result]" → CTA: "Comment [WORD] for the PDF"

### 7. Myth-Buster Template
"After [X years] in the field..." → Identify damaging misconception → 3 paragraphs debunking with reality → Superior alternative → "Have you fallen for this?"

## Carousel Architecture (AIDA)

| Slide Range | Phase | Purpose |
|---|---|---|
| Slide 1 | Attention (Cover) | Benefit-driven headline, value prop, visual hook. Must stop the scroll. |
| Slides 2–4 | Interest | Name the problem, share data or a contrarian point, agitate the pain |
| Slides 5–8 | Desire/Detail | Step-by-step methodology, proof, exact "how-to" |
| Final Slide | Action | Single CTA — comment keyword, save, follow |

**Technical specs:** PDF only (preserves fonts). Portrait 1080×1350px. <3MB. Body text ≥24pt, headers 36–48pt. Contrast ratio ≥4.5:1. 8–12 slides maximum.

**Progressive disclosure pattern:** Each slide pays off the previous one while seeding curiosity for the next. Example: "Most tenants think X." → "But here's what actually happens..." → "The reason? Three things."

## Hub & Spoke Repurposing Model

**The Hub** = one long-form asset (newsletter, detailed case study, podcast episode). Written/hosted on an owned domain.

**Fracture into 6 Spokes:**
1. **Story** — personal anecdote extracted from the Hub
2. **Observation** — macro-trend from the Hub distilled to one punchy insight
3. **Carousel/Thread** — step-by-step logic reformatted as swipeable slides
4. **Contrarian Take** — controversial point from the Hub isolated to polarize
5. **Past vs. Present** — transformation or paradigm shift from the Hub
6. **Listicle** — core bullet points stripped for rapid scannability

**Temporal staggering:** Publish spokes over 4–6 weeks. Each spoke routes traffic back to the Hub.

**Recycling rule:** After 6 months, high-performing posts can be reformatted (text → carousel), tone-adjusted, or republished. New followers have no memory.

## DM Outreach Sequence

| Phase | Objective | How |
|---|---|---|
| Pre-Outreach | Establish familiarity | Comment on their posts before sending a connection request |
| Hook (≤50 words) | Human context, no pitch | Reference their recent activity, profile, or shared context only |
| Value Deposit | Psychological reciprocity | Send a relevant artifact (framework, insight, article) — no ask |
| Pain Identification | Find operational challenges | Ask a specific, thoughtful question using "signposting" (your own experience) |
| The Transition | Move off-platform | Only after multi-message engagement: propose a 15-min call |

**Best send times:** Tuesday–Thursday, 8–11am recipient's local time.
**Never connect-and-ghost.** A replied DM makes the prospect 70% more likely to see your future posts.

## Signposting (Anti-AI Inoculation)

To avoid the 55% engagement penalty for AI-sounding text, frame every lesson through personal experience:
- "When reviewing a retail tenant's lease in [city], we found..."
- "I learned this the hard way after a client dispute in 2023..."
- "After analyzing 300+ CAM reconciliations, the pattern is..."

Specific numbers, named scenarios, and first-person failure stories make content algorithmically indistinguishable from organic human writing.
