SLIDE 1:
Five MRI CAM recovery errors that produce wrong statements.
How to find them before tenants do.

SLIDE 2:
Error 1: Expense group GL account gaps
A GL account exists in your chart of accounts but is not assigned to any expense group.
The expense never reaches the recovery calculation.
Most common trigger: new sub-accounts created mid-year and never mapped.
A 180,000 SF building with seven unmapped accounts after a migration lost $53,700 per year. inside the normal variance range, so no one flagged it.

SLIDE 3:
Error 2: Allocation method mismatch
MRI supports Pro-Rata by Total SF, Pro-Rata by Occupied SF, Fixed Percentage, and Fixed Amount.
Using occupied SF when the lease says total SF with gross-up produces a $21,000 difference for a 12,000 SF tenant in an 80%-occupied building.
The wrong method may violate lease terms, creating overbilling exposure or leakage.

SLIDE 4:
Error 3: Recovery parameter misconfiguration
Gross-up disabled for a building at 78% occupancy: landlord absorbs all vacancy cost variance.
Cap type set to non-cumulative when the lease says cumulative: identical in Year 1, diverges every subsequent year.
Compounding from actual expenses instead of capped amounts: cap resets higher every year actuals exceed the limit.

SLIDE 5:
Error 4: Charge code linking breaks
The linking chain: Expense Group > Recovery Analysis > Charge Code > Tenant Charge.
A break at any point produces incorrect output.
Most common: a new recovery analysis created after a pool restructuring, but the charge code still points to the old analysis. Billing continues. Calculation is wrong.

SLIDE 6:
Error 5: Period and timing issues
Fiscal year mismatch: recovery analysis configured for July-June on a lease that reconciles January-December.
Accrual cutoff: December expenses not accrued when the recovery analysis runs in January.
The reconciliation goes out with 11 months of actual expenses and a missing month.

SLIDE 7:
The validation workflow
Export Recovery Analysis Detail and GL Trial Balance for the same property and period.
Compare expense totals. the recovery analysis should match the recoverable accounts in the GL.
Select three tenants: one large, one small, one mid-year event.
Rebuild the calculation manually. Compare each component: expenses, share, gross-up, cap, base year excess.

SLIDE 8:
This validation takes 3-4 hours per property.
It catches configuration errors that otherwise persist for years.
