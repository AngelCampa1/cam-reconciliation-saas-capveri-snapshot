Most property managers think CPA-reviewed CAM reconciliations are what tenants hire. They are also what landlords should be doing.

The CPA guide to CAM reconciliation audit uses a lease matrix approach: one row for each GL account in the pool, one column for each lease provision that affects it. The matrix shows, for every expense and every tenant, whether the charge is supported by the lease.

Property managers with ten leases can build this matrix manually. Property managers with fifty leases cannot do it manually in the time available during reconciliation season.

What the matrix exposes is not usually fraud. It exposes the categories that have accumulated without anyone verifying lease support. An admin fee charged on top of a management fee when the lease allows only one. An elevator maintenance contract included in a building where the tenant's lease excludes base building mechanical systems. A landscaping invoice allocated to a tenant whose lease specifically excludes exterior improvements.

Each of these errors has a dollar amount. Each of them compounds across the tenant's lease term. A $3,000 annual admin fee error over a 7-year lease is $21,000. easily within audit territory.

The CPA process that catches these errors is designed to run after the statement is issued, during an audit engagement. The same logic works before the statement is issued, as a review.

The question is not whether someone will eventually run the matrix. It is whether the property manager runs it first.
