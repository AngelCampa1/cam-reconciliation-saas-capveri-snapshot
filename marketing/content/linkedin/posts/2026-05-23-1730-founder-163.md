From Angel Campa, CapVeri founder:

A belief that shaped how we built the calculation engine: AI should not make financial decisions.

There are two things CapVeri uses AI for. One: extracting lease terms from PDF documents. Gross-up thresholds, cap structures, base years, exclusion lists. The extraction is AI-assisted.

But every extraction requires human review before it affects any calculation. The extracted value is surfaced for a property accountant to confirm or correct. The AI output doesn't go directly into the reconciliation.

Two: nothing else. The reconciliation calculation itself uses hard-coded logic with deterministic rules. BOMA 2024 standards. Gross-up math. Cap application. Pro-rata allocation. These are not probabilistic outputs. They're exact calculations with traceable inputs and auditable outputs.

The reason for this separation is straightforward. A CAM reconciliation is a financial record that landlords and tenants are contractually bound by. If a tenant auditor asks why a specific charge was calculated a certain way, the answer cannot be "the model thought this was right." It needs to be "this is the formula, this is the input, this is the lease clause that supports it."

Every dollar has to be traceable. That requires deterministic math, not probabilistic approximation.
