The CapVeri sample report includes findings across four categories: gross-up errors, cap application issues, expense pool inclusion problems, and pro-rata denominator variances.

Each finding is shown with: the tenant name, the calculation element that generated the finding, the ERP's output, CapVeri's lease-based calculation, and the dollar variance between the two.

The format is designed to be actionable. A property accountant can take the finding list directly to the ERP configuration and make the corrections before statements go out.

If you want to see what the output looks like before deciding whether the tool fits your workflow, the sample report is the clearest starting point.
