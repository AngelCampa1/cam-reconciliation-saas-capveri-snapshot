Hook line (say on camera, first 3 seconds):
"Most CAM reconciliation errors aren't found in the calculation. They're found in the gap between what the lease says and what the ERP was configured to do."

Talking points:
- Property accountants are not the problem. The process is the problem. - The ERP configuration is set up at lease execution. Leases run for 5, 10, sometimes 20 years. Amendments happen. Renewals happen. The configuration doesn't always follow. - Three types of events that create configuration drift: lease amendments, personnel turnover, and portfolio acquisitions. Each one can break the link between what's configured and what the lease requires. - The fix is a comparison step: calculate independently from the lease terms, compare to ERP output, surface any differences. - This is not a technology problem. The comparison can be done manually. The problem is that it rarely is, because no one owns that step in the workflow. - CapVeri owns that step. You upload a CSV. We calculate from your lease terms. The comparison output shows you what to fix before statements go out.

Closing line:
"The verification step is the product. Everything else is infrastructure to make it run without requiring a consultant every year."
