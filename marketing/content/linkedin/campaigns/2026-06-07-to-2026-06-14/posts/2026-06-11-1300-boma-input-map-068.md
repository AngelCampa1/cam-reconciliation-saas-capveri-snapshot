BOMA 2024 does not change the CAM formula by itself.

It changes inputs that the formula may use.

Rentable area.
Load factor.
Amenity allocation.
Outdoor tenant areas.
Building support zones.
Measurement source.

That is why the transition needs an input map before the first reconciliation using updated measurements.

For each tenant, the file should show:

Prior measurement basis.
Current measurement basis.
Lease language that allows or blocks the change.
Old share.
New share.
Effective date.

CapVeri can align the reconciliation math to the current inputs. The lease still decides which inputs apply.
