Before a CAM workbook gets debated, the export stack has to tie.

For Yardi teams, the first pass is not a formula review. It is a file review:

Recovery Analysis.
GL Analytics.
Rent Roll with Lease Charges.

Same property. Same period. Detail-level output. Flat CSV.

If those files do not agree, every downstream discussion gets noisier. A gross-up issue might be real. A cap issue might be real. But the team is still building on a file set that has not earned trust yet.

This is the part teams can inspect in minutes:

Tie the exports first, then test the lease math.

Where does your team usually find the first mismatch: recovery report, GL detail, or rent roll?
