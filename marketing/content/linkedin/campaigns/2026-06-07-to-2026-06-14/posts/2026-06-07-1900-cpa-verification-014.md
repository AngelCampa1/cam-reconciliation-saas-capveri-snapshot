A good CAM calculation should be straightforward for a CPA to verify.

Not because the lease is simple.

Because the path is visible.

Input file.
Lease clause.
Expense classification.
Gross-up factor.
Pro-rata share.
Cap test.
Estimate credit.
Final true-up.

Each step should have a source and a number.

That is the reason CapVeri keeps calculation logic deterministic. The same inputs should rebuild the same answer later, even if the person reviewing the file was not involved in the original reconciliation.

The best audit trail is not a prettier explanation.

It is a reproducible one.
