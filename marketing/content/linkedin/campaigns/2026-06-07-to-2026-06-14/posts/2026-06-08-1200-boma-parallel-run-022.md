The BOMA 2024 rollout step worth protecting:

Run the reconciliation both ways before go-live.

Current measurement.
Updated measurement.
Tenant by tenant comparison.
Variance review.
System check.

That parallel run catches the quiet mistakes:

Building total updated, suite RSF not updated.
Pro-rata shares no longer sum correctly.
Gross-up denominator still uses the old rentable area.
One lease references a fixed BOMA version while another allows updates.

CapVeri treats BOMA 2024 as an input-control project, not a slogan.

The first live statement should not be the first test.
