The cap percentage gets the attention.

The base usually decides the answer.

A CAM cap can start from prior-year actual controllable expenses.

It can start from a fixed base year.

It can compound from a prior ceiling.

It can interact with carve-outs for taxes, insurance, utilities, or management fees.

The percentage is not portable unless the base is the same.

For capped tenants, the file should show:

Base amount.
Source year.
Expense categories included.
Excluded categories.
Cap percentage.
Current ceiling.
Actual controllable amount.

Without that, "5%" is just a label.
