When the Yardi export settings changes, the tenant note should change with it.

Input: Yardi can be the system of record without being the only calculation check.

Review: review recovery pool, share type, gross-up, cap, and exclusion settings against the lease.

Evidence: The report can run cleanly while one tenant uses the wrong share type.

Close: Export the data, recalculate independently, then compare.

A correct ERP report means the system followed its setup. It does not by itself show the setup matches the lease.

A missing source note can create the same delay as a wrong formula.
