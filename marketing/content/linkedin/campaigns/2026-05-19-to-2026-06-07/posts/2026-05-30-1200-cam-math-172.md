A review of the pro-rata denominator belongs in CAM close before final billing.

1. Start with the lease rule. A tenant share is only as reliable as the denominator behind it.

2. Check the source data. Match the denominator to the lease, not just the building setup screen.

3. Run the calculation in a way someone else can follow. Building RSF, occupied RSF, floor RSF, and pool RSF can all produce different percentages.

4. Save the support. Store the denominator source next to the calculation output.

One clear memo now can prevent a long email thread later.

The close file should show both the accounting source and the lease logic.
