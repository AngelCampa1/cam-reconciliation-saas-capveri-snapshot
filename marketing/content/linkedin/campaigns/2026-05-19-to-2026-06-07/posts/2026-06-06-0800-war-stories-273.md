A review of the audit defense packet belongs in CAM close before final billing.

1. Start with the lease rule. Tenant questions are easier to answer when the packet already explains the math.

2. Check the source data. Include source export, lease clause reference, calculation trace, and variance notes.

3. Run the calculation in a way someone else can follow. A tenant asking about landscaping should see the GL lines, allocation basis, and exclusion review.

4. Save the support. Build the audit trail before sending the statement.

Waiting until an auditor asks for support usually creates more work than assembling it up front.

Use this as a first-pass control, then move exceptions into a separate queue.
