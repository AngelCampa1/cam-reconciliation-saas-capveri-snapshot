Export-based verification should leave a trail a second reviewer can follow.

1. Start with the lease rule. CAM verification can work from exports without replacing the ERP.

2. Check the source data. Use CSV, Excel, and PDF outputs as the input layer.

3. Run the calculation in a way someone else can follow. Keep Yardi or MRI as the system of record, then run an independent lease-term calculation beside it.

4. Save the support. Verify the output before changing the system.

A tie-out proves totals. It does not by itself show recoverability.

The best version of this review is boring and repeatable.
