Start with export-based verification.

Lease rule: CAM verification can work from exports without replacing the ERP.

Source file: use CSV, Excel, and PDF outputs as the input layer.

Tenant impact: Keep Yardi or MRI as the system of record, then run an independent lease-term calculation beside it.

Close file: Verify the output before changing the system.

A controller should be able to review this without reopening last year's workbook.

When the rule changes by tenant, do not let the portfolio default hide it.
