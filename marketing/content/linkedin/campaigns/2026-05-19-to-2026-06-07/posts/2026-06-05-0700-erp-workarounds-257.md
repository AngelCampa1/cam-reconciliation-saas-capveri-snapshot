MRI export review: the CAM check to run before billing.

Start with the control question: MRI recovery billing still needs lease-level QA.

Source check: compare share type, billing pool, lease exclusions, and gross-up rules before statements go out.

Where it breaks: A tenant can be assigned to the right pool and still use the wrong denominator.

Evidence to keep: GL source, lease rule, calculation input, and tenant impact.

Before billing: Run a tenant-by-tenant exception report before final billing.

The issue is usually configuration drift, not a broken ERP.

The close file should show both the accounting source and the lease logic.
