A review of the gross-up factor belongs in CAM close before final billing.

1. Start with the lease rule. Gross-up should apply to variable expenses only.

2. Check the source data. Compare actual occupancy to the lease target before applying a factor.

3. Run the calculation in a way someone else can follow. If actual occupancy is already at or above the target, the factor should be 1.0.

4. Save the support. Separate fixed and variable expenses before the reconciliation run.

Treat the exception note as part of the reconciliation, not an afterthought.

Use the review to separate calculation errors from documentation gaps.
