GL export QA should leave a trail a second reviewer can follow.

1. Start with the lease rule. An export can balance and still be incomplete for CAM work.

2. Check the source data. Check date filters, accrual timing, entity scope, and excluded accounts.

3. Run the calculation in a way someone else can follow. A late-posted accrual can be outside the export even when the report total ties to the ledger run.

4. Save the support. Save the export parameters with the reconciliation file.

Save the setup screenshot or export parameter while the file is still open.

Keep the final answer tied to the exact export used for billing.
