Spreadsheet risk should leave a trail a second reviewer can follow.

1. Start with the lease rule. Excel is flexible, but flexibility can hide broken assumptions.

2. Check the source data. Check hard-coded factors, copied formulas, hidden tabs, and stale denominators.

3. Run the calculation in a way someone else can follow. A workbook can pass tie-out while one tenant row still points to last year's denominator.

4. Save the support. Move repeated reconciliation logic into a traceable workflow.

One clear memo now can prevent a long email thread later.

The cleanest workflow keeps the source export and lease rule beside the output.
