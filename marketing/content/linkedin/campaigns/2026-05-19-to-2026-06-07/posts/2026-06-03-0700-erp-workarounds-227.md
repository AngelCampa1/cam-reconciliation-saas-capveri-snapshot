MRI export review should leave a trail a second reviewer can follow.

1. Start with the lease rule. MRI recovery billing still needs lease-level QA.

2. Check the source data. Compare share type, billing pool, lease exclusions, and gross-up rules before statements go out.

3. Run the calculation in a way someone else can follow. A tenant can be assigned to the right pool and still use the wrong denominator.

4. Save the support. Run a tenant-by-tenant exception report before final billing.

The charge can be right and still be poorly supported.

Keep the backup simple enough for someone outside accounting to follow.
