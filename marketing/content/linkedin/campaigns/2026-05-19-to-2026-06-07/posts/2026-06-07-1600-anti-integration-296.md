Export-based verification: the CAM check to run before billing.

Start with the control question: CAM verification can work from exports without replacing the ERP.

Source check: use CSV, Excel, and PDF outputs as the input layer.

Where it breaks: Keep Yardi or MRI as the system of record, then run an independent lease-term calculation beside it.

Evidence to keep: GL source, lease rule, calculation input, and tenant impact.

Before billing: Verify the output before changing the system.

The integration is not the proof. The calculation trace is the proof.

If the input came from an ERP export, keep the report settings with it.
