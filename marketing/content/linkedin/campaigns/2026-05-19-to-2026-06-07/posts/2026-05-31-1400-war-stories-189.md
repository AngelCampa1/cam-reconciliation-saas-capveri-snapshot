A review of tenant dispute prep belongs in CAM close before final billing.

1. Start with the lease rule. Many disputes start with missing support, not a dramatic accounting error.

2. Check the source data. Review the lines tenants are most likely to question before the packet is sent.

3. Run the calculation in a way someone else can follow. Taxes, insurance, management fees, CapEx, and administrative charges need especially clear support.

4. Save the support. Attach the support while the reconciliation is still fresh.

If the lease rule changed, the calculation note should change with it.

If a statement needs revision, this note should explain exactly where to look.
