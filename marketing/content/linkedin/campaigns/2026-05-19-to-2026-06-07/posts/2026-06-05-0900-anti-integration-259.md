The packet gets easier to review when deterministic CAM math is documented early.

1. Start with the lease rule. Financial math should be deterministic and auditable.

2. Check the source data. Use rules, formulas, and source-backed inputs for allocations.

3. Run the calculation in a way someone else can follow. AI can help read a document, but the charge calculation should come from explicit lease terms.

4. Save the support. Keep calculation logic separate from document extraction.

If the rule is hard to explain internally, it will be harder to support externally.

Use the review to separate calculation errors from documentation gaps.
