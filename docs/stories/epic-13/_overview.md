# Epic 13: Reporting & Export UI

## Purpose
Build the reporting and export interfaces that generate tenant packets, ERP write-back files, and variance reports. This epic completes the reconciliation workflow by enabling users to distribute results to tenants and sync back to source accounting systems.

## Business Value
Enables automated report generation and ERP integration, allowing organizations to close reconciliation cycles quickly. Supports multiple export formats (PDF, Yardi, MRI, Excel) to meet diverse system requirements. Provides variance analysis comparing current year to prior year for trend analysis. All exports are branded and include detailed documentation for audit trails.

## Dependencies
- **Epic 1**: Design System & UI Foundation (base components)
- **Epic 4.5**: API Client & Contract Testing (generated API client)
- **Epic 7**: Reconciliation API (export endpoints)
- **Epic 12**: Reconciliation Grid UI (reconciliation context)
