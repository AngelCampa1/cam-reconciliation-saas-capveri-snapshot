# Epic 17: Advanced Expense Pools

## Purpose
Enable complex pool configurations and split allocations for sophisticated CAM reconciliation scenarios.

## Business Value
Commercial properties often have complex expense allocation requirements - retail centers with anchor tenant exclusions, mixed-use buildings with different pool structures per use type, or properties with specialized common areas. This epic provides the flexibility to model any allocation scenario.

## Dependencies
- Epic 6 (Financial Calculation Engine) - Pool aggregation logic
- Epic 7 (Reconciliation API) - Pool data in calculations
