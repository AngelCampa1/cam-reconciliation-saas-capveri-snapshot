# Epic 10: Property & Lease Management UI

## Purpose
Builds the CRUD interfaces for properties, units, and leases - the master data that drives all calculations. The UI must provide excellent UX for managing complex hierarchical data with the recovery profile editor being the most sophisticated component.

## Business Value
Enables CAM analysts to efficiently create, edit, and manage the property portfolio including units and leases. Provides clear interfaces for configuring complex lease terms and recovery profiles that determine calculation behavior.

## Dependencies
- **Epic 1**: Design system (forms, tables, modals)
- **Epic 4**: Backend CRUD APIs
- **Epic 4.5**: Generated API client
- **Epic 9**: Authentication (protected routes)
