# Cumulative CAM Cap Bank Calculator

An 8-year horizon spreadsheet that models how a CAM expense cap interacts with cumulative bank balances when actual CAM oscillates above and below the cap ceiling. Asset managers use it to scrub lease language (cumulative vs non-cumulative, compounding vs flat) and to forecast unrecoverable overage before sending year-end reconciliation packets. Pairs with the live tool at https://www.capveri.com/tools/cumulative-cap-bank-calculator.
