# CAM Pre-Send Packet Checklist

A 5-section operator checklist for property managers reviewing the year-end CAM reconciliation packet before it goes to tenants. Sections cover lease abstract review, GL tie-out, allocation accuracy, cap and base-year application, and statement format with supporting schedules. Each item names a recurring failure mode, explains why it matters under audit, and references the source documents needed to verify the answer. Pairs with the resource page at https://www.capveri.com/resources/cam-pre-send-packet-checklist.
