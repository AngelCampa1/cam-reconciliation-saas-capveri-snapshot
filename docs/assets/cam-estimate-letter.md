A 2-page forward-looking CAM Estimate / Budget Letter template for property managers sending the annual CAM estimate to tenants at the start of each lease year. Page 1 is a formal cover letter invoking the applicable lease section, explaining that this is an estimate (not a reconciliation), and summarizing the key drivers of change from the prior year (insurance, landscaping rebid, utility rates) in a driver table. Page 2 (Exhibit A) contains the full CAM Budget Estimate Detail table with prior-year actuals, budget-year estimates, percent change, and notes for each expense category, plus pro-rata math, a new monthly estimate line, and a tenant acknowledgment signature block.
