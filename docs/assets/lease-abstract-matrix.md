## Pro-Rata Formula (Column D)

```excel
=IF($B$2=0, 0, C{r}/$B$2)
```

- `$B$2` = Building GLA (entered in building inputs row)
- Returns 0 if GLA = 0 to prevent division errors

## Discrepancy Flag Formula (Column O)

Three-level waterfall — first matching condition wins:

```excel
=IF(AND(H{r}<>"", H{r}<>"None", I{r}=""),
    "RED: CAM Cap % missing",
  IF(AND(F{r}<>"", G{r}<>""),
    "YELLOW: Base year + stop both set",
  IF(AND(N{r}<>"", N{r}<={current_year - 2}),
    "ORANGE: Reconciliation overdue",
  "")
))
```

### Flag Definitions

| Flag | Condition | Risk |
|------|-----------|------|
| 🔴 RED: CAM Cap % missing | Cap Type is set (not blank, not "None") but Cap % is empty | CAM cap will not be enforced in billing; tenant may be overbilled |
| 🟡 YELLOW: Base year + stop both set | Both F (Base Year) and G (Expense Stop) are populated | Typically only one applies per lease; double-entry may indicate data entry error |
| 🟠 ORANGE: Reconciliation overdue | Last Reconciled Year <= current year − 2 | Reconciliation is more than 12 months past due; exposure to tenant disputes |

### Conditional Formatting

The Discrepancy Flag column (O) uses Excel conditional formatting:

| Rule | Fill | Font Color |
|------|------|-----------|
| Starts with "RED" | `#FFC7CE` (light red) | `#9C0006` (dark red) |
| Starts with "YELLOW" | `#FFEB9C` (light yellow) | `#9C6500` (dark amber) |
| Starts with "ORANGE" | `#FFCC99` (light orange) | `#7F3F00` (dark orange) |

## Discrepancy Summary Tab

Pulls flagged rows from Tenant Matrix using:

```excel
=IF('Tenant Matrix'!O{r}<>"", 'Tenant Matrix'!A{r}, "")
```

Empty rows are suppressed. All 15 data rows are checked.

## Edge Cases

| Scenario | Behavior |
|----------|---------|
| GLA = 0 | Pro-Rata shows 0 (not error) |
| Cap Type = "None" | No RED flag triggered (intentional — cap is explicitly waived) |
| Last Reconciled Year blank | No ORANGE flag (blank treated as unknown, not overdue) |
| Both base year and expense stop blank | No YELLOW flag |
