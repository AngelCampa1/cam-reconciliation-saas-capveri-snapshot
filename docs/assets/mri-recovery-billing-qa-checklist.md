## Summary

A 4-page error checklist for property managers using MRI Residential/Commercial for CAM recovery billing. Mirrors the Yardi checklist structure with MRI-specific terminology (Cost Centers, Recovery Billing module, MRI Lease Abstract, MRI expense pools).

## Sections

1. MRI GL Export QA — Cost Center date range, recoverable category filter, duplicate journal entry check, intercompany elimination, accruals, prepaid amortization, capital/expense classification, management fee Cost Center, admin fee, insurance cross-check.
2. Recovery Billing Setup QA — Lease Abstract pool assignment, expense pool definitions, pro-rata calculation method setting, MRI cap tracker, exclusion matrix, base year lock, tenant GLA, reconciliation period.
3. Output Validation — tie to MRI GL trial balance, tenant share manual check, prior-year comparison, PDF review, backup schedules, second reviewer sign-off.
4. Common MRI Pitfalls — expense pool includes non-recoverable accounts; recovery billing run before all invoices posted; prior-year adjustment posted to wrong period.
