A generic, 4-page year-end CAM Reconciliation Statement template for property managers sending standard statements to tenants. The template covers a cover page with all required property/tenant/preparer fields, a CAM Pool Summary table (janitorial through admin fee, with gross-up and exclusions memo), a Tenant Allocation section showing pro-rata math and true-up balance, a line-item Supporting Expense Schedule, and a certification/signature block with built-in audit-rights notice.
