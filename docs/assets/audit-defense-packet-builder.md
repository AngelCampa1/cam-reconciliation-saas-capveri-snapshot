## Summary

A 5-6 page guide for property managers assembling documentation in response to a tenant CAM audit. Covers the 3 goals of an audit defense packet, a 12-item required documents checklist, a recommended folder/file-naming convention, a 7-row response timeline table, an 8-row common audit issues table, and a fill-in cover letter template.

## Sections

1. What Is an Audit Defense Packet? — 3 goals: prove accuracy, demonstrate compliance, reduce dispute liability.
2. Required Documents Checklist — 12 items including signed lease, 3 years of statements, GL trial balance, vendor invoices, management agreement, insurance declarations, property tax bills, gross-up/cap/pro-rata worksheets, BOMA certification, capital approval docs.
3. Document Organization Guide — recommended folder structure and file naming convention.
4. Response Timeline — Day 0 through Day 90 with responsible party column.
5. Common Audit Issues — 8 rows: Issue | How to Prevent | Documentation to Include.
6. Cover Letter Template — formal letter to accompany the audit response packet.
