## Summary

A 4-page error checklist for property managers and accountants exporting CAM data from Yardi Voyager or Yardi Commercial CAM. Covers GL export checks, recovery setup checks, output validation, and common export pitfalls.

## Sections

1. GL Export QA — date range, account code filtering, journal entry deduplication, intercompany eliminations, accruals, prepaid amortization, capital/expense split, management fee, admin fee, insurance cross-check.
2. Recovery Setup QA — recovery code, GBA denominator, gross-up flag, cap setup, exclusion list, base year lock, GLA, reconciliation period.
3. Output Validation — tie to GL trial balance, tenant share manual check, prior-year export, PDF review, backup schedules, second reviewer sign-off.
4. Common Yardi Pitfalls — wrong CAM pool code; company-level management fee overriding lease; gross-up applying to fixed expenses.
