# Tenant CAM Dispute Response Letter

A landlord-side response letter for tenant CAM objections, backup requests, and dispute follow-up. Includes a full-form formal letter, a short-form alternate cover letter with attachment cover sheet, and a glossary of CAM review terms. Merge fields (e.g., `[TENANT NAME]`, `[AUDIT WINDOW DAYS]`, `[LEASE SECTION REFERENCES]`) are bracketed so the PDF can be search-replaced before sending. Pairs with the resource page at https://www.capveri.com/resources/tenant-dispute-response-letter-template.
