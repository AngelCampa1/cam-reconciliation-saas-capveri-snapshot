## How to update

After completing a feature task:

1. Update the relevant domain doc below
2. Add a `> Last updated:` line at the top of the doc with the date and a brief description
3. Bump the date in this index next to the doc you changed

If the feature affects product positioning or messaging, also update `product-marketing-context.md` via the `/product-marketing-context` skill.
