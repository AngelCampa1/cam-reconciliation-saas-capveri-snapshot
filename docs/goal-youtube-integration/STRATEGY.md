## 2. Architecture: one canonical source + a generator (the reusable pattern)

The three apps (`marketing/` Next.js, `frontend/` Vite, `backend/` FastAPI) are **separate packages**
with no shared workspace. Mirroring the existing design-tokens pipeline
(`design-tokens.json` → `npm run tokens` → `frontend/.../tokens.css` + `backend/.../tokens.py`):

```
marketing/data/videos.json        ← CANONICAL SOURCE OF TRUTH (hand-edited)
        │
        │  node scripts/generate-videos.mjs   (run via `npm run videos` at repo root or marketing)
        ▼
   ├── backend/app/services/email/videos.py            (generated Python module)
   └── frontend/src/generated/videos.ts                (generated TS module)
```

**Adding a future video = edit `videos.json`, run `npm run videos`, place where wanted.** That is the
reusable pattern. Generated files carry a "DO NOT EDIT — generated by scripts/generate-videos.mjs" header.

`videos.json` shape (follows existing `marketing/data/*.json` convention: `lastUpdated` + named array):
```jsonc
{
  "lastUpdated": "2026-06-09",
  "videos": [
    {
      "slug": "walkthrough-yardi-csv",
      "youtubeId": "kCMogQ3ZJck",
      "title": "CAM Reconciliation Demo: Upload a Yardi CSV and Catch the Errors",
      "shortLabel": "...",          // humanized, 3rd-grade, on-site caption (gated)
      "description": "...",          // humanized, 3rd-grade, 1-2 sentences (gated)
      "stage": "demo",
      "durationSeconds": null,       // fill when known; used for VideoObject schema
      "uploadDate": "2026-06-09",    // ISO 8601 for VideoObject schema
      "thumbnailUrl": "https://i.ytimg.com/vi/kCMogQ3ZJck/hqdefault.jpg",
      "placements": ["product-tour", "sample-report", "app:first-import", "email:welcome"]
    }
  ]
}
```

Local reference requirement is satisfied by `videos.json` + the existing `youtube-production/videos/*`
tree (we also stamp the live `youtubeId` into each `youtube-field.md`).

## 3. Reusable embed components (one per app)

- **Marketing:** `VideoEmbed` (client component) — click-to-load **facade**: renders the `i.ytimg.com`
  thumbnail + pill play button; swaps in a `youtube-nocookie.com` iframe only on click. MDX-exported as
  `<VideoEmbed slug="..." />`. Plus `videoObject` JSON-LD factory in `lib/structured-data.ts`.
- **Frontend app:** `VideoThumbnail` + `VideoModal` (shadcn Dialog lightbox, `youtube-nocookie.com` iframe
  loaded only when opened). Reads `frontend/src/generated/videos.ts`.
- **Email:** `video_card` Jinja2 macro in `_components.html` — linked static thumbnail
  (`img.youtube.com/vi/<id>/mqdefault.jpg`) → YouTube watch URL (email can't embed video). Reads `videos.py`.

**Required marketing config change:** `next.config.ts` CSP `frame-src` must add `https://www.youtube-nocookie.com`
(facade loads nocookie iframe); add `i.ytimg.com` to image handling if `next/image` is used (we use `<img>`, so optional).
