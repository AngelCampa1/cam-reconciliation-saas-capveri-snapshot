## Goal statement
Import the improvements, new rules, and learnings developed in camaudit-v2 into
camaudit, where they apply. Explicit priority: **update models** (e.g. data
extraction now uses **Gemini Flash 3.1 Lite**, replacing Claude 3.5 Sonnet).
No regressions. Multiple review/fix cycles until nothing remains to fix.

## How this goal runs
- Orchestrator decomposes; sub-agents explore/implement/verify/review.
- All implementation happens in a git worktree, reviewed before merge to master.
- Each imported change is verified (tests + typecheck for impacted projects) before "done".
- This LEDGER is the durable cross-session record. Update it every batch.
