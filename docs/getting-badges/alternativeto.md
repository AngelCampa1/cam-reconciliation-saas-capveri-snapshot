**What is CapVeri?**

```text
CapVeri is CAM reconciliation verification software for commercial landlords and property management teams.

It imports GL, rent roll, and lease data from Yardi, MRI, RealPage, AppFolio, Excel, or any system that exports CSV or Excel files. Then it checks CAM reconciliation math against lease terms before statements go out.

CapVeri catches issues like gross-up on fixed expenses, wrong denominators, cap tracking errors, CapEx in the recoverable pool, lease exclusions, management-fee mistakes, and missing audit evidence. Each finding includes the dollar impact and the lease context needed for review.

CapVeri is not a full property management system. It is the verification and audit layer for teams that already have a PM system but still need confidence that their CAM output is correct.
```
