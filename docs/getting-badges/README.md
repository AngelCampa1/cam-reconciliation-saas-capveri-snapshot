This folder was the copy-paste kit for submitting CapVeri to SaaSHub, AlternativeTo, Product Hunt, G2, and BetaList. It was never used for a submission.

The files were meant to be used in this order:

1. Read [master-profile.md](./master-profile.md) for the intended CapVeri facts, pricing, assets, URLs, keywords, and competitor names.
2. Check [requirements-matrix.md](./requirements-matrix.md) before each submission, so the form of the day would match the platform requirements verified on 2026-05-15.
3. Open the platform file and copy each field into the form:
   - [saashub.md](./saashub.md)
   - [alternativeto.md](./alternativeto.md)
   - [producthunt.md](./producthunt.md)
   - [g2.md](./g2.md)
   - [betalist.md](./betalist.md)
4. Use [assets-checklist.md](./assets-checklist.md) to export the right logo, screenshot, and banner sizes.
5. Review [review-log.md](./review-log.md) for the factual, platform-fit, humanizer, and consistency checks.

## Recommended Submission Order

None of these was ever reached. The order was:

1. **SaaSHub**: fastest directory fit, direct SaaS submission, domain verification improves priority.
2. **AlternativeTo**: useful for long-tail comparison discovery once CapVeri could be listed against Yardi, MRI, RealPage, AppFolio, and Excel/manual alternatives.
3. **G2**: highest trust value, but category placement would need owner follow-through, because the closest existing categories may not fully match CAM reconciliation.
4. **BetaList**: submit only if CapVeri were still eligible as recently launched. If the editorial team treated it as too mature, use the pack for an advertising or boost decision instead.
5. **Product Hunt**: save for a coordinated launch day, not a passive directory submission.

## Owner-Only Steps

These could not be completed from repo content, and none of them was ever done:

- Create or log into each platform account.
- Use a `capveri.com` domain email where a platform requires domain verification.
- Confirm the G2 seller/legal details if the form asks for company headquarters, legal entity, or tax/contact fields.
- Confirm whether CapVeri has custom critical date alarms before requesting G2 Lease Administration.
- Confirm Product Hunt maker usernames before scheduling the launch.
- Confirm CapVeri has not launched on Product Hunt in the last six months before scheduling.
- Confirm CapVeri has not already been featured on BetaList, unless the prior feature was pre-launch and this is the launch feature.
- Decide whether to pay for BetaList priority, SaaSHub promotion, G2 paid profile upgrades, or any boost packages.
- Pick the Product Hunt launch date and time.
