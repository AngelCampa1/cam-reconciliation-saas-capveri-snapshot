## Edge Cases

1. **Email template images**: If logo or hero images reference the old CDN/domain, update URLs and re-upload assets.
2. **CORS origins order**: When updating allowed origins in `config.py`, ensure the new `capveri.com` variants are added (not just replacing old entries) if you need to support both domains during a transition period.
3. **Sentry project slug**: Sentry project names are managed in the Sentry dashboard. Code-side changes (release names, environment tags) are sufficient for now.
